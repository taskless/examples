# Taskless Examples

Small, runnable examples from the [Taskless](https://taskless.io) blog. Each folder is its own Taskless project with its own CLI version, so one example can't break another.

| Example | What it shows |
| --- | --- |
| [`many-languages-one-ruleset`](many-languages-one-ruleset/) | Runtime rules that check agreement across files and languages |

Larger studies with a pinned corpus have their own repos: [`blog-taskless-ty`](https://github.com/taskless/blog-taskless-ty) and [`blog-taskless-nori-lint`](https://github.com/taskless/blog-taskless-nori-lint).
