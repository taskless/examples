# Taskless Examples

Small, runnable examples from the [Taskless](https://taskless.io) blog. Each folder is its own Taskless project with its own CLI version, so one example can't break another. Folders are named after their posts.

| Example | What it shows |
| --- | --- |
| [`many-languages-one-ruleset`](many-languages-one-ruleset/) | Runtime rules that check agreement across files and languages |
| [`type-shaped-gap`](type-shaped-gap/) | ty's `redundant-condition` checks rebuilt as Taskless rules, measured beside ty, pylint and ruff |
| [`strict-skills-on-every-commit`](strict-skills-on-every-commit/) | nori-lint's static SKILL.md rules rebuilt as Vale rules, measured on 365 public skills |
| [`deterministic-desloppification`](deterministic-desloppification/) | Effect coding traits turned into Taskless rules |
